# Portfolio

Static portfolio for GitHub Pages: <https://gnaneshgnani.github.io>.

## Local preview

Open `index.html` directly in a browser, or from the resume directory run:

```bash
./open-portfolio.sh
```

## GitHub Pages

Publish the contents of this `portfolio/` directory from the root of the `GnaneshGnani.github.io` repository. The resume PDFs are stored under `resumes/` so the links work after deployment.
